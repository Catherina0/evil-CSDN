# evil-CSDN
씨발 CSDN

CSDN이 한 멍청한 일들

1. 무단 재게재 콘텐츠: CSDN은 많은 블로그 글과 기술 자료를 허가 없이 재게재하고 적절한 출처나 링크를 표시하지 않았다.
2. 유료 열람: CSDN은 다른 사람의 원본 콘텐츠를 허가 없이 유료 열람으로 설정하고 무료 자료를 CSDN에 크롤링하여 포인트 다운로드로 설정했다.
3. 개인정보 문제: CSDN 등록 및 사용 중에 대량의 스팸 메일을 받았으며, CSDN에 데이터 유출이나 사용자 정보의 부적절한 사용이 있을 가능성이 있다.
4. 중국어 검색 오염: 중국어 검색 엔진으로 질문을 검색할 때, CSDN의 유료이고 저품질인 콘텐츠가 검색 결과 상위를 차지하여 정보 획득에 영향을 미친다.
5. Gitcode 표절: 허가 없이 GitHub의 코드를 대량으로 Gitcode로 크롤링하고 CSDN의 모든 링크를 Gitcode 링크로 교체했다.

요약하자면, CSDN의 어머니는 죽었다!
