# evil-CSDN
Чорт забяры CSDN

Дурныя справы, якія зрабіў CSDN

1. Неаўтарызаванае паўторнае апублікаванне кантэнту: CSDN паўторна апублікаваў вялікую колькасць артыкулаў блогаў і тэхнічных матэрыялаў без дазволу, не даўшы адпаведнага прызнання або спасылак.
2. Платнае чытанне: CSDN несанкцыянавана ўсталяваў арыгінальны кантэнт іншых як платнае чытанне, прасканаваў бясплатныя матэрыялы ў CSDN і ўсталяваў іх як спампоўкі па балам.
3. Праблемы з прыватнасцю: Падчас рэгістрацыі і выкарыстання CSDN мы атрымалі вялікую колькасць спаму, што прымушае нас падазраваць, што CSDN можа мець уцечкі даных або нядармовае выкарыстанне інфармацыі карыстальнікаў.
4. Забруджанне кітайскага пошуку: Пры выкарыстанні кітайскіх пошукавых сістэм для пошуку пытанняў, вялікая колькасць платнага і нізкакачэственнага кантэнту з CSDN займае першыя пазіцыі ў выніках пошуку, што ўплывае на атрыманне інфармацыі.
5. Плагіят Gitcode: Без дазволу скапіравана вялікая колькасць кода з GitHub у Gitcode, дзе ўсе спасылкі CSDN былі заменены спасылкамі Gitcode.

У выніку, маці CSDN памерла!
