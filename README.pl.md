# evil-CSDN
Do diabła CSDN

Głupie rzeczy, które zrobił CSDN

1. Nieautoryzowane ponowne publikowanie treści: CSDN ponownie opublikował dużą ilość artykułów blogowych i materiałów technicznych bez zgody, nie podając odpowiedniego uznania ani linków.
2. Płatne czytanie: CSDN nieuprawnienie ustawił oryginalną treść innych jako płatne do odczytu, przeszukując darmowe materiały do CSDN i ustawiając je jako pobrania punktowe.
3. Problemy z prywatnością: Podczas rejestracji i korzystania z CSDN otrzymałem dużą ilość spamu, podejrzewając, że CSDN może mieć wycieki danych lub nieodpowiednie wykorzystanie informacji użytkowników.
4. Zanieczyszczenie chińskiego wyszukiwania: Korzystając z chińskich wyszukiwarek do wyszukiwania pytań, duża ilość płatnych i niskiej jakości treści z CSDN zajmuje pierwsze pozycje w wynikach wyszukiwania, wpływając na zdobywanie informacji.
5. Plagiat Gitcode: Bez uprawnień skopiowano dużą ilość kodu z GitHub do Gitcode, zastępując wszystkie linki CSDN linkami Gitcode.

Podsumowując, matka CSDN umarła!
