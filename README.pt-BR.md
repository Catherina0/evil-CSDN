# evil-CSDN
Merda do CSDN

Coisas idiotas que o CSDN fez

1. Republicação não autorizada de conteúdo: O CSDN republicou uma grande quantidade de artigos de blogs e materiais técnicos sem autorização, sem dar os devidos créditos ou links.
2. Leitura paga: O CSDN configurou indevidamente conteúdo original de terceiros como leitura paga, baixando materiais gratuitos para o CSDN e configurando-os como downloads por pontos.
3. Problemas de privacidade: Durante o registro e uso do CSDN, foram recebidas grandes quantidades de spam, suspeitando que o CSDN possa ter vazamentos de dados ou uso inadequado das informações dos usuários.
4. Poluição da busca em chinês: Ao usar mecanismos de busca chineses para procurar perguntas, uma grande quantidade de conteúdo pago e de baixa qualidade do CSDN ocupa as primeiras posições dos resultados de busca, afetando a obtenção de informações.
5. Plágio do Gitcode: Sem autorização, copiou grandes quantidades de código do GitHub para o Gitcode, substituindo todos os links do CSDN por links do Gitcode.

Em resumo, a mãe do CSDN morreu!
