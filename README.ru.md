# Злой CSDN
## К чёрту CSDN

Плохие поступки CSDN:

1. Несанкционированное воспроизведение контента: CSDN воспроизводит большое количество статей из блогов и технических материалов без разрешения, без надлежащего указания авторства или ссылок.

2. Платное чтение: CSDN устанавливает оригинальный контент других пользователей как платный для чтения на своей платформе без разрешения, а также индексирует бесплатные материалы на CSDN и устанавливает их в качестве платных загрузок.

3. Проблемы с конфиденциальностью: Во время регистрации и использования CSDN я получил большое количество спам-писем, подозревая, что CSDN могла допустить утечку данных или неправомерное использование информации пользователей.

4. Загрязнение китайских поисковых систем: При поиске информации в китайских поисковых системах большое количество платного низкокачественного контента с CSDN занимает верхние позиции в результатах поиска, что влияет на поиск информации.


5. Плагиат в GitCode: несанкционированное копирование большого объема кода с GitHub в GitCode и замена всех ссылок CSDN ссылками на GitCode.

В заключение, CSDN, сука блят!
