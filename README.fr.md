# CSDN, le mal incarné
## CSDN, c'est de la merde

Les méfaits de CSDN :

1. Reproduction non autorisée de contenu : CSDN reproduit un grand nombre d'articles de blog et de documents techniques sans autorisation, sans attribution ni lien.

2. Contenu payant : CSDN propose du contenu original d'autrui comme contenu payant sans autorisation et récupère du contenu gratuit pour le proposer en téléchargement payant.

3. Problèmes de confidentialité : Lors de mon inscription et de mon utilisation de CSDN, j'ai reçu de nombreux spams, ce qui me laisse penser que CSDN a peut-être divulgué des données ou fait un usage abusif des informations des utilisateurs.

4. Pollution des moteurs de recherche chinois : Lors de mes recherches sur les moteurs de recherche chinois, de nombreux contenus payants et de mauvaise qualité provenant de CSDN occupent les premières positions des résultats, ce qui nuit à la recherche d'informations.

5. Plagiat de code GitCode : CSDN récupère sans autorisation une grande quantité de code GitHub vers GitCode et remplace tous les liens CSDN par des liens GitCode.

En conclusion, CSDN, nique ta mère!
