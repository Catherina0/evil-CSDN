# evil-CSDN
Eik šūnie CSDN

Kvaili dalykai, kuriuos padarė CSDN

1. Neleistinas turinio pakartotinis skelbimas: CSDN pakartotinai paskelbė didelį kiekį tinklaraščių straipsnių ir techninės medžiagos be leidimo, nedavęs tinkamo priskyrimo ar nuorodų.
2. Mokama skaityti: CSDN neteisėtai nustatė kitų originalų turinį kaip mokamą skaitymą, nuskaityo nemokamas medžiagas į CSDN ir nustatė jas kaip taškų atsisiuntimus.
3. Privatumo problemos: Registruodamiesi ir naudodamiesi CSDN gavome didelius kiekius šlamšto laiškų, dėl ko įtariame, kad CSDN gali turėti duomenų nutekėjimų ar netinkamą naudotojų informacijos naudojimą.
4. Kinų paieškos taršymas: Naudojant kinų paieškos sistemas ieškant klausimų, didelis kiekis mokamo ir žemos kokybės turinio iš CSDN užima pirmas vietas paieškos rezultatuose, paveikiant informacijos gavimą.
5. Gitcode plagiatas: Be leidimo buvo nukopijuotas didelis kiekis kodo iš GitHub į Gitcode, kur visos CSDN nuorodos buvo pakeistos Gitcode nuorodomis.

Santrauka: CSDN motina mirė!
