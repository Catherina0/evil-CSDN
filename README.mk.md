# evil-CSDN
Ќе те јебе CSDN

Глупи работи што ги направи CSDN

1. Неовластено повторно објавување на содржина: CSDN повторно објави голем број блог статии и технички материјали без дозвола, без да даде соодветно припишување или врски.
2. Платено читање: CSDN неовластено го поставил оригиналниот содржина на другите како платено читање, ги скенирал бесплатните материјали во CSDN и ги поставил како преземања поени.
3. Проблеми со приватност: За време на регистрацијата и користењето на CSDN добивме големи количини спам, што нè наведува да се сомневаме дека CSDN можеби има цурење на податоци или несоодветна употреба на корисничките информации.
4. Загадување на кинеското пребарување: При користење на кинески пребарувачи за пребарување на прашања, голем број платен и нискоквалитетен содржина од CSDN зафаќа првите позиции во резултатите од пребарувањето, што влијае на добивањето информации.
5. ПLAGIAT на Gitcode: Без дозвола е копиран голем број код од GitHub во Gitcode, каде што сите врски на CSDN се заменети со врски на Gitcode.

Накратко, мајката на CSDN е мртва!
