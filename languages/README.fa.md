# evil-CSDN
لعنت به CSDN

چیزهای احمقانه‌ای که CSDN انجام داده است

1. بازنشر غیرمجاز محتوا: CSDN مقدار زیادی از مقالات وبلاگ و مواد فنی را بدون مجوز بازنشر کرده و اعتبار یا پیوندهای مناسبی ارائه نداده است.
2. خواندن پولی: CSDN به‌صورت غیرمجاز محتوای اصلی دیگران را به‌عنوان خواندن پولی تنظیم کرده، مواد رایگان را به CSDN کشانده و آن‌ها را به‌عنوان دانلود امتیازی تنظیم کرده است.
3. مشکلات حریم خصوصی: در حین ثبت‌نام و استفاده از CSDN، مقدار زیادی ایمیل هرزنامه دریافت کردیم که ما را به این فکر واداشته که CSDN ممکن است دچار نشت داده یا استفاده نامناسب از اطلاعات کاربران شده باشد.
4. آلودگی جستجوی چینی: هنگام استفاده از موتورهای جستجوی چینی برای جستجوی سوالات، مقدار زیادی از محتوای پولی و کیفیت پایین از CSDN جایگاه‌های اولیه در نتایج جستجو را اشغال می‌کند که بر کسب اطلاعات تأثیر می‌گذارد.
5. دزدی Gitcode: بدون مجوز، مقدار زیادی از کد از GitHub به Gitcode کپی شده و تمام پیوندهای CSDN با پیوندهای Gitcode جایگزین شده‌اند.

در مجموع، مادر CSDN مرده است!
