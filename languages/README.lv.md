# evil-CSDN
Pie velna CSDN

Muļķīgas lietas, ko CSDN ir izdarījis

1. Neatļauta satura atkārtota publicēšana: CSDN atkārtoti publicējis lielu daudzumu emuāru rakstu un tehnisko materiālu bez atļaujas, nesniedzot pienācīgu atsaukšanos vai saites.
2. Maksas lasīšana: CSDN neatļauti iestatījis citu oriģinālo saturu kā maksas lasīšanu, norāvis bezmaksas materiālus uz CSDN un iestatījis tos kā punktu lejupielādes.
3. Konfidencialitātes problēmas: Reģistrējoties un izmantojot CSDN, saņēmām lielas daudzumus surogātpasta ziņojumus, kas liek mums šaubīties, vai CSDN varētu būt datu noplūdes vai nepiemērota lietotāju informācijas izmantošana.
4. Ķīniešu meklēšanas piesārņojums: Izmantojot ķīniešu meklētājprogrammas, lai meklētu jautājumus, liels daudzums maksas un zemas kvalitātes satura no CSDN ieņem pirmās vietas meklēšanas rezultātos, ietekmējot informācijas iegūšanu.
5. Gitcode plagāts: Bez atļaujas tika nokopēts liels daudzums koda no GitHub uz Gitcode, kur visi CSDN saišu tika aizstātas ar Gitcode saitēm.

Kopsavilkumā, CSDN māte ir mirusi!
