# evil-CSDN
Verdammter CSDN

Die dummen Sachen, die CSDN getan hat

1. Unbefugte Weiterverbreitung von Inhalten: CSDN hat eine große Anzahl von Blog-Artikeln und technischen Materialien ohne Genehmigung weiterverbreitet und keine angemessene Namensnennung oder Links angegeben.
2. Bezahlpflichtiges Lesen: CSDN hat fremde Originalinhalte unbefugt als bezahlbares Lesematerial eingestellt und kostenlose Materialien auf CSDN hochgeladen, um sie als punktebasierte Downloads anzubieten.
3. Datenschutzprobleme: Während der Registrierung und Nutzung von CSDN wurden große Mengen an Spam-E-Mails erhalten, was den Verdacht erweckt, dass CSDN möglicherweise Datenlecks oder unangemessene Nutzung von Benutzerinformationen haben könnte.
4. Verschmutzung der chinesischen Suche: Bei der Verwendung chinesischer Suchmaschinen zur Suche nach Fragen nehmen zahlreiche kostenpflichtige und minderwertige Inhalte von CSDN die ersten Suchergebnispositionen ein und beeinträchtigen die Informationsbeschaffung.
5. Gitcode-Plagiat: Ohne Genehmigung wurden große Mengen an Code von GitHub zu Gitcode kopiert, und alle CSDN-Links wurden durch Gitcode-Links ersetzt.

Zusammenfassend: Die Mutter von CSDN ist tot!
