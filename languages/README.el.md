# evil-CSDN
Γαμήσου CSDN

Χαζομάρες που έκανε το CSDN

1. Μη εξουσιοδοτημένη αναδημοσίευση περιεχομένου: Το CSDN αναδημοσίευσε μεγάλο αριθμό άρθρων ιστολογίων και τεχνικών υλικών χωρίς άδεια, χωρίς να δίνει κατάλληλη αναφορά ή συνδέσμους.
2. Πληρωμένη ανάγνωση: Το CSDN όρισε μη εξουσιοδοτημένα το αρχικό περιεχόμενο άλλων ως πληρωμένη ανάγνωση, σαρώνοντας δωρεάν υλικά στο CSDN και ορίζοντάς τα ως λήψεις με πόντους.
3. Προβλήματα απορρήτου: Κατά την εγγραφή και χρήση του CSDN λάβαμε μεγάλες ποσότητες spam, γεγονός που μας κάνει να υποψιαζόμαστε ότι το CSDN μπορεί να έχει διαρροές δεδομένων ή ακατάλληλη χρήση πληροφοριών χρηστών.
4. Ρύπανση της κινεζικής αναζήτησης: Όταν χρησιμοποιούμε κινεζικές μηχανές αναζήτησης για αναζήτηση ερωτήσεων, μεγάλη ποσότητα πληρωμένου και χαμηλής ποιότητας περιεχομένου από το CSDN καταλαμβάνει τις πρώτες θέσεις στα αποτελέσματα αναζήτησης, επηρεάζοντας τη λήψη πληροφοριών.
5. Πλαγιογράφηση Gitcode: Χωρίς άδεια, αντιγράφηκε μεγάλη ποσότητα κώδικα από το GitHub στο Gitcode, όπου όλοι οι σύνδεσμοι του CSDN αντικαταστάθηκαν με συνδέσμους Gitcode.

Συνοπτικά, η μητέρα του CSDN πέθανε!
