# evil-CSDN
ไปตายเถอะ CSDN

เรื่องโง่ๆ ที่ CSDN ทำ

1. การเผยแพร่เนื้อหาโดยไม่ได้รับอนุญาต: CSDN ได้เผยแพร่บทความบล็อกและวัสดุทางเทคนิคจำนวนมากโดยไม่ได้รับอนุญาต และไม่ให้เครดิตหรือลิงก์ที่เหมาะสม
2. การอ่านแบบเสียเงิน: CSDN ได้ตั้งเนื้อหาต้นฉบับของผู้อื่นเป็นการอ่านแบบเสียเงินโดยไม่ได้รับอนุญาต และสแกนวัสดุฟรีไปยัง CSDN และตั้งค่าเป็นการดาวน์โหลดคะแนน
3. ปัญหาความเป็นส่วนตัว: ระหว่างการลงทะเบียนและการใช้งาน CSDN เราได้รับอีเมลสแปมจำนวนมาก ซึ่งทำให้เราสงสัยว่า CSDN อาจมีการรั่วไหลของข้อมูลหรือการใช้ข้อมูลผู้ใช้ไม่เหมาะสม
4. การปนเปื้อนของการค้นหาภาษาจีน: เมื่อใช้เครื่องมือค้นหาภาษาจีนในการค้นหาคำถาม เนื้อหาที่เสียเงินและมีคุณภาพต่ำจาก CSDN จะครองตำแหน่งแรกในผลการค้นหา ส่งผลกระทบต่อการรับข้อมูล
5. การลอกเลียน Gitcode: โดยไม่ได้รับอนุญาต ได้คัดลอกโค้ดจำนวนมากจาก GitHub ไปยัง Gitcode โดยแทนลิงก์ CSDN ทั้งหมดด้วยลิงก์ Gitcode
