# зло-CSDN
## да чорта з CSDN

Дрэнныя рэчы, якія зрабіў CSDN:

1. Несанкцыянаванае капіраванне кантэнту: CSDN скапіраваў вялікую колькасць артыкулаў у блогу і тэхнічных матэрыялаў без дазволу, без належнага ўказання аўтарства або спасылак.

2. Платны кантэнт: CSDN усталёўваў арыгінальны кантэнт іншых карыстальнікаў як платны кантэнт на CSDN без дазволу і сканаваў бясплатныя матэрыялы на CSDN і ўсталёўваў іх як загрузкі на аснове балаў.

3. Праблемы з прыватнасцю: Атрымліваў вялікую колькасць спам-лістоў падчас рэгістрацыі і выкарыстання CSDN, падазраючы, што CSDN мог уцекваць дадзеныя або няправільна выкарыстоўваць інфармацыю карыстальніка.

4. Забруджванне кітайскага пошуку: Пры пошуку пытанняў з дапамогай кітайскіх пошукавых сістэм вялікая колькасць платнага, нізкаякаснага кантэнту з CSDN займала верхнія пазіцыі вынікаў пошуку, што ўплывала на пошук інфармацыі.

5. Плагіят GitCode: Несанкцыянаванае сканіраванне вялікай колькасці кода GitHub на GitCode і замена ўсіх спасылак CSDN спасылкамі GitCode.

У заключэнне, CSDN, ты мёртвы!
