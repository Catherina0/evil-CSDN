# evil-CSDN
Do hája CSDN

Hlúpe veci, ktoré CSDN urobil

1. Neoprávnené znovuverejnenie obsahu: CSDN znovuverejnil veľké množstvo blogových článkov a technických materiálov bez povolenia, bez toho, aby poskytol primerané uvedenie autora alebo odkazy.
2. Platené čítanie: CSDN neoprávnene nastavil originálny obsah iných ako platené čítanie, prehľadal bezplatné materiály do CSDN a nastavil ich ako bodové sťahovania.
3. Problémy so súkromím: Počas registrácie a používania CSDN sme dostali veľké množstvo spamu, čo nás prinútilo podozrieť, že CSDN môže mať úniky údajov alebo neprimerané použitie informácií používateľov.
4. Znečistenie čínskeho vyhľadávania: Pri použití čínskych vyhľadávačov na hľadanie otázok zaberajú veľké množstvo plateného a nízko kvalitného obsahu z CSDN prvé pozície vo výsledkoch vyhľadávania, čo ovplyvňuje získavanie informácií.
5. Plagiát Gitcode: Bez povolenia bolo skopírované veľké množstvo kódu z GitHubu do Gitcode, kde boli nahradené všetky odkazy CSDN odkazmi Gitcode.

Zhrnutie, matka CSDN je mŕtva!
