# evil-CSDN
Чорт забирай CSDN

Дурні справи, які зробив CSDN

1. Неавторизоване повторне опублікування контенту: CSDN повторно опублікував велику кількість статей блогів і технічних матеріалів без дозволу, не надавши належного вказування авторства або посилань.
2. Платне читання: CSDN несанкціоновано встановив оригінальний контент інших як платне читання, просканувавши безкоштовні матеріали до CSDN і встановивши їх як завантаження за бали.
3. Проблеми з приватністю: Під час реєстрації та використання CSDN ми отримали велику кількість спаму, підозрюючи, що CSDN може мати витоки даних або неналежне використання інформації користувачів.
4. Забруднення китайського пошуку: Використовуючи китайські пошукові системи для пошуку питань, велика кількість платного і низькоякісного контенту з CSDN займає перші позиції в результатах пошуку, впливаючи на отримання інформації.
5. Плагіат Gitcode: Без дозволу скопійовано велику кількість коду з GitHub до Gitcode, замінивши всі посилання CSDN посиланнями Gitcode.

У підсумку, мати CSDN померла!
