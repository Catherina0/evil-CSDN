# evil-CSDN
Kurat CSDN

Lollused, mida CSDN tegi

1. Loata sisu taasavalikustamine: CSDN avaldas uuesti suure hulga ajaveebi artikleid ja tehnilisi materjale ilma loata, andmata sobivat tunnustust ega linke.
2. Tasuline lugemine: CSDN seadis teiste originaalsisu tasuliseks lugemiseks ilma loata, kraapis tasuta materjalid CSDN-i ja seadis need punktide allalaadimiseks.
3. Privaatsusprobleemid: CSDN-i registreerimise ja kasutamise ajal saime palju rämpsposti, mis paneb meid kahtlema, kas CSDN-il võib olla andmelekkimisi või sobimatut kasutajateabe kasutamist.
4. Hiina otsingu saastumine: Hiina otsingumootorites küsimuste otsimisel võtab CSDN-i tasuline ja madala kvaliteediga sisu esimesed kohad otsingutulemustes, mis mõjutab info hankimist.
5. Gitcode-i plagiaat: Loata kopeeriti suur hulk koodi GitHub-ist Gitcode-i, kus kõik CSDN-i lingid asendati Gitcode-i linkidega.

Kokkuvõttes on CSDN-i ema surnud!
