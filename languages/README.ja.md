# evil-CSDN
くそったれCSDN

CSDNがした馬鹿げたこと

1. 無断転載：CSDNは大量のブログ記事や技術資料を無断で転載し、適切なクレジットやリンクを表示していない。
2. 有料閲覧：CSDNは他人のオリジナルコンテンツを無断で有料閲覧に設定し、無料資料をCSDNにクロールしてポイントダウンロードに設定している。
3. プライバシー問題：CSDNの登録と使用中に大量のスパムメールを受け取り、CSDNにデータ漏洩やユーザー情報の不適切な使用がある疑いがある。
4. 中国語検索の汚染：中国語検索エンジンで質問を検索する際、CSDNの有料で低品質なコンテンツが検索結果の上位を占め、情報取得に影響を与えている。
5. Gitcodeの盗用：許可なくGitHubのコードを大量にGitcodeにクロールし、CSDNのすべてのリンクをGitcodeリンクに置き換えている。

まとめると、CSDNの母親は死んだ！
